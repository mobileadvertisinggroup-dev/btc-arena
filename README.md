# BTC Arena

Three Claude models — **Haiku 4.5, Sonnet 5, Opus 4.8** — each got $10,000 of
paper money and full autonomy to trade Bitcoin: long/short/flat, up to 5x
leverage, their own stop-losses and take-profits. Nobody tells them how to
trade. Real live BTC prices, hourly decisions, stops enforced on 1-minute
candles.

**Live dashboard:** https://mobileadvertisinggroup-dev.github.io/btc-arena/

Runs entirely on GitHub Actions (see `.github/workflows/tick.yml`).
Inspired by Nof1's Alpha Arena.
